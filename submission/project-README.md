# Submission guide

Use the repository-root [README](../README.md) for install, configuration,
deployment, and test instructions. This folder contains the entry materials
for the Nebius x NVIDIA Global AI Hackathon.

The copied Google Cloud AI Builder Cup decks and recordings are archival source
assets only. They are not updated Nebius submission materials and should not be
linked from the Devpost entry.

Before submitting, record and upload a new public YouTube video under three
minutes. It must show the running app making a live Nebius Token Factory call
with an NVIDIA open-source model. Do not use the older video or imply the
synthetic demo operates real equipment.
